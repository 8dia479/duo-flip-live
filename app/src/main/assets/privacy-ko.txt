# Duo Fold Live 개인정보 처리방침

시행일: 2026년 10월 17일. 개발자: Joe Consorti. 이 방침은 Duo Fold Live(org.duofold.live)의 GitHub 및 Google Play 버전에 적용됩니다.

## 화면 처리 및 접근성

별도로 명시적으로 동의한 경우, Duo는 폴딩 애니메이션이 켜져 있고 휴대전화 잠금이 해제된 동안 권한을 허용한 Shizuku 또는 기존 루트 도우미를 사용해 화면에 표시되는 앱 콘텐츠를 캡처하고 복제합니다. 화면 콘텐츠에는 개인정보가 포함될 수 있습니다. 화면 프레임은 글래스 효과와 화면 전환을 위해 기기의 메모리 안에서만 처리합니다. Duo는 화면 녹화를 저장하거나 캡처한 프레임을 업로드하지 않습니다. 보안 또는 보호된 화면은 캡처하지 않습니다. 이 권한 기반 처리 방식은 Android의 MediaProjection 권한 대화상자를 사용하지 않습니다.

접근성 서비스는 다른 앱 위를 포함해 여러 디스플레이에 비대화형 애니메이션 오버레이를 표시합니다. 창의 글자나 UI 콘텐츠를 가져오지 않으며, 접근성 스크린샷을 찍거나 제스처를 수행하거나 탭을 자동 실행하지 않습니다. Duo는 장애가 있는 사용자를 위한 접근성 도구로 설계되지 않았습니다. 화면 처리는 접근성 스크린샷 API가 아니라 별도의 권한 기반 도우미가 수행합니다. 선택 기능인 사용자 배경화면 도우미는 UiAutomation 창 이벤트, 루트 패키지 이름, 포커스 및 화면 위치 정보를 사용해 홈 화면과 시스템 창을 식별하고 잠금 화면 UI 아래를 포함한 사진의 위치를 조정합니다. UI 요소의 글자를 읽거나 사용자 동작을 자동 실행하지 않습니다. 이 메타데이터는 기기 안에만 저장되며 사용자가 명시적으로 공유하기로 선택한 진단 보고서에 포함될 수 있습니다. 접근성 데이터가 개발자에게 자동 전송되지는 않습니다.

## 권한 기반 접근 및 기기 변경

권장 연결 방식은 Shizuku+입니다. 사용자가 별도로 설치하고 권한을 허용해야 합니다. 기존 루트 권한은 선택 가능한 대안이며, Duo가 기기를 루팅하지는 않습니다. 도우미는 필터링된 삼성 배경화면·힌지 진단 정보를 읽고 지원되는 화면 전환을 제어합니다. 설정 과정에서는 설명을 제공하고 사용자의 승인을 받은 뒤 양쪽 홈 화면의 배경화면 연결을 변경합니다. 사용자 사진 사용은 선택 사항입니다. 사용자 배경화면 호스트는 Android 계측 기능과 권한 기반 창 API를 사용합니다. 선택 기능인 화면 켜짐 유지는 삼성의 접었을 때 잠금 설정을 변경하고, 기기를 접는 동안 제한된 시간 동안 화면이 꺼지지 않도록 합니다. 이러한 기능은 기기 안에서 동작합니다.

## 사진, 설정 및 진단 정보

Android 문서 선택기를 통해 선택한 사진은 배경화면에 사용하기 위해 앱 전용 저장 공간으로 복사됩니다. 사진 라이브러리에 있는 원본은 삭제하지 않습니다. 환경설정, 동의 선택, 배경화면 사진 및 자르기 정보, 배경화면 진단 보고서는 교체하거나 삭제하거나 앱을 제거할 때까지 기기 안에 보관됩니다. 일반적인 애니메이션 프레임은 사진 파일로 보관하지 않고 메모리에서 처리합니다.

진단 정보에는 기기 및 빌드 정보, 힌지 각도, 디스플레이 상태, 도우미 오류, 앱 작업·구성 요소 이름 및 시간 정보가 포함될 수 있습니다. 상태 기록은 최대 288개 샘플로 제한되며 새 샘플이 추가될 때 24시간이 지난 샘플은 삭제됩니다. 다른 진단 정보도 저장 개수 또는 파일 크기가 제한된 기록이나 로컬 보고서 파일을 사용합니다. 보고서는 사용자가 직접 복사하거나 내보내거나 공유하지 않는 한 기기 안에만 남습니다. 공유하기 전에 보고서 내용을 확인하세요. 클립보드, 다운로드 폴더 또는 다른 앱에 복사한 항목은 별도로 삭제해야 합니다.

## 수집, 공유 및 외부 서비스

Duo에는 계정 시스템, 광고 SDK, 분석 서비스 또는 자동 서버 업로드 기능이 없습니다. 개인정보를 판매하지 않습니다. 사용자가 켠 기능을 제공하기 위해 기기 내 처리가 필요합니다. 링크는 GitHub, Shizuku 문서 및 GitHub 버전의 선택적 Ko-fi 후원과 같은 외부 서비스로 연결됩니다. 해당 서비스에는 각각 자체 개인정보 처리방침이 적용됩니다. Google은 Play 구매를 처리하며 Duo는 결제 카드 정보를 받지 않습니다. Play 버전에는 후원 안내가 표시되지 않습니다.

사용자가 GitHub에 제출한 이슈와 첨부 파일은 GitHub에서 달리 안내하지 않는 한 공개됩니다. 공개 보고서에 민감한 화면 내용이나 개인정보를 게시하지 마세요.

## 사용자의 선택 및 삭제

'개인정보 및 제어' 화면에서 각 동의를 거부하거나 철회하고, Duo의 모든 백그라운드 작업을 중지하거나 선택적 화면 켜짐 유지 기능을 변경할 수 있습니다. '모두 중지'는 애니메이션, 사용자 배경화면 및 화면 켜짐 유지 관리를 비활성화하지만 사진과 설정은 유지합니다. 권한 기반 접근이 가능한 경우 Duo는 다른 앱이나 사용자가 그 사이 설정을 변경하지 않았다면, 처음 동의 후 변경하기 전에 저장한 접었을 때 잠금 설정을 복원하려고 시도합니다. 이 방침보다 오래된 빌드에서는 원래 설정을 저장하지 않았으므로 업그레이드 후 삼성 설정의 '접었을 때 잠금'을 직접 확인하세요. 복원이 보류 중인 경우 Shizuku를 다시 연결하고 '개인정보 및 제어'를 다시 열거나 삼성 설정에서 직접 변경하세요.

원한다면 Shizuku 앱에서 Shizuku 권한을 해제하고 Android 설정에서 접근성 및 다른 앱 위에 표시 권한을 해제할 수 있습니다. 작업을 중지해도 이전 삼성 홈 화면 배경화면이 자동으로 복원되지는 않습니다. 삼성 설정에서 다른 배경화면을 선택하세요. Duo의 앱 저장 공간을 삭제하거나 앱을 제거하면 앱 전용 사진, 환경설정 및 진단 파일이 삭제됩니다. 내보내거나 공유한 보고서와 사진은 별도로 삭제해야 합니다. Duo에는 계정이나 자동 데이터 업로드가 없으므로 개발자가 보유한 계정 데이터를 삭제할 필요는 없습니다.

## 문의 및 업데이트

개인정보 관련 질문이나 이전에 개발자와 공유한 보고서의 삭제 요청은 https://github.com/joeconsorti/duo-fold-live/issues 를 이용하세요. 민감한 내용을 다시 게시하지 말고 어떤 보고서인지 식별할 수 있도록 설명해 주세요. 개발자는 자신이 관리하는 자료를 삭제할 수 있지만, 제3자 서비스에 복사된 자료에는 해당 서비스의 정책이 적용됩니다. 방침 변경 사항은 이 파일에 게시하고 앱에도 포함합니다.
